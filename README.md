# PackPort

语言 / Language：**[简体中文](README.zh-CN.md)** · **[English](README.en.md)**

PackPort 是一个面向 Fedora 的桌面软件包安装器，支持将本地 RPM、DEB、AppImage、Flatpak bundle 和 Flatpak reference 文件拖入窗口后安装。

PackPort 不会声称所有 Debian 软件包都能在 Fedora 上运行：DEB 会先通过 Alien 转换为 RPM，随后仍由 DNF 执行正常的依赖检查。
