# PackPort v0.1.0

PackPort v0.1.0 is the first formal release of the Fedora drag-and-drop package installer.

## Highlights

- Install local RPM, DEB, AppImage, Flatpak bundle, and Flatpak reference files from one GTK4/Libadwaita interface.
- Review package name, version, architecture, signature state, SHA-256, source path, scope, and risk before installation.
- Follow real percentage output when available, or stage-based progress otherwise.
- Keep the graphical process unprivileged; system operations use a fixed-command Polkit helper.
- Use Simplified Chinese or English automatically according to the system locale.

DEB support is best-effort: Alien converts the package to RPM and DNF5 still performs normal dependency checks. PackPort does not use dependency-bypass switches.

## Install on Fedora 43

Download both release assets, then verify and install the RPM:

```sh
sha256sum --check SHA256SUMS
sudo dnf install ./packport-0.1.0-1.fc43.noarch.rpm
```

Launch **PackPort** from the application menu or run `packport`.

The published RPM is `noarch`, but this release is tested and supported on Fedora 43 x86_64. Runtime tools such as DNF5, Flatpak, Alien, dpkg, and squashfs-tools are installed as RPM dependencies.

## Known limitations

- DEB dependencies and maintainer scripts may not map safely to Fedora.
- Flatpak references can require network access and remote confirmation.
- AppImage metadata extraction falls back to a generic icon when embedded metadata cannot be read.
- Snap, generic archives, software search, updates, and installed-app management are not included.
